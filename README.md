# MARK/THREE — Tic-Tac-Toe

MARK/THREE is a polished, browser-based Tic-Tac-Toe game built with React, TypeScript, Vite, and Tailwind CSS.

## Features

- Local two-player games and single-player games against the house.
- Easy and unbeatable hard computer modes.
- Pre-game X/O selection, persistent win/loss/draw records, animated marks and winning lines.
- Sound effects with a visible mute control.
- Clipboard sharing for completed boards and match records.

## Run locally

```bash
pnpm install
pnpm dev
```

## Vercel

Vercel will use the included `vercel.json`, run `vite build`, and deploy the generated `dist/public` folder.
